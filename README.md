# Kho Âm Thanh PXDE

Kho hiệu ứng âm thanh dùng chung cho logo animation của PIXELDESIGN.

- `index.html` — trang nghe/lọc/tải
- `data.json` — danh sách âm (tên, loại, vibe, nguồn, dự án, prompt, 4 bản)
- `sfx/` — file WAV 48kHz

Thêm âm mới: chép file vào `sfx/`, thêm mục tương ứng vào `data.json`.
